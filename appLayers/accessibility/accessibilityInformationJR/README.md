# 鉄道施設に関するバリアフリー情報（JR） (LaWA)

国土交通省の「歩行者移動支援サービスに関するデータサイト」で公開されているJR駅のバリアフリー情報を取得し、SVGMap上に表示するレイヤーアプリケーションです。

各駅を段差対応状況に応じた色で表示し、駅を選択するとエレベーター、エスカレーター、案内設備、障害者対応設備などの情報を確認できます。

## データソース

| 項目 | URL |
| --- | --- |
| データ掲載ページ | [鉄道施設に関するバリアフリー情報（JR）](https://www.hokoukukan.go.jp/metadata/resource/10) |
| データ説明書 | [鉄道施設に関するバリアフリー情報（JR）データ説明書](https://www.hokoukukan.go.jp/uploads/22/10/mlit_jr_sta.pdf) |
| 取得するCSV | `https://www.hokoukukan.go.jp/uploads/22/10/mlit_jr_sta1.csv` |

CSVファイルはレイヤーの読み込み時に取得するため、このリポジトリには収録していません。

## 主な機能

- 緯度・経度を持つJR駅の地図表示
- CSVの「段差への対応」に基づく駅シンボルの色分け
- 駅名、路線名、鉄道事業者、所在地の表示
- ホーム数や段差が解消されているホーム数の表示
- エレベーター、エスカレーター、傾斜路の設置状況表示
- 誘導ブロック、案内設備、障害者対応設備の表示
- 車いすで乗降可能なホームや転落防止設備の表示
- 読み込んだ駅の表示件数とエラー状態の表示

## 導入方法

`Container.svg`に次の`animation`要素を追加します。

```xml
<animation
  x="-30000"
  y="-30000"
  width="60000"
  height="60000"
  xlink:href="./appLayers/accessibility/accessibilityInformationJR/accessibilityInformationJR.svg"
  data-cross-origin-proxy-required="true"
  class="バリアフリー"
  title="鉄道施設に関するバリアフリー情報（JR）"
  visibility="hidden"/>
```

SVGMapをHTTP(S)サーバーで配信し、レイヤー一覧から「鉄道施設に関するバリアフリー情報（JR）」を有効にします。

## 操作方法

レイヤーを有効にするとCSVを読み込み、位置情報を持つ駅を地図上に描画します。駅シンボルをクリックすると、その駅についてCSVに値がある項目を一覧表示します。

### 駅シンボルの凡例

| 色 | CSVの「段差への対応」 |
| --- | --- |
| 青 | `○` |
| 赤 | `×` |
| グレー | `○`、`×`以外または未設定 |

色分けはCSVに記載された値をそのまま分類したものであり、個別経路や利用時点での移動可否を保証するものではありません。

## データの読み込みと表示

- CSVは`svgMap.getCORSURL()`を通して取得します。
- 文字コードはShift_JISとして読み込み、利用できない場合はUTF-8での読み込みを試みます。
- 引用符、フィールド内のカンマ、改行に対応したCSVパーサーで解析します。
- CSVの見出しに存在する表示対象項目だけを駅の詳細情報に設定します。
- 緯度または経度を数値として取得できない行は表示しません。
- CSVはレイヤーの初回読み込み時に取得し、自動更新は行いません。最新データを再取得するにはページを再読み込みしてください。

## CORS

配信元CSVはSVGMapアプリケーションとは異なるオリジンにあるため、このレイヤーは`svgMap.getCORSURL()`を使用します。親SVGMapにCORSプロキシを設定し、プロキシ側で`www.hokoukukan.go.jp`へのGETリクエストを許可してください。

CSVの文字コードをブラウザー側で判定するため、プロキシはレスポンス本文を文字列へ変換せず、元のバイト列のまま返す必要があります。`Container.svg`のレイヤー定義にも`data-cross-origin-proxy-required="true"`を設定します。

## ファイル構成

- `accessibilityInformationJR.svg`: 駅シンボルとコントローラー定義
- `accessibilityInformationJR.html`: 操作画面、凡例、表示件数
- `accessibilityInformationJR.js`: CSV取得、解析、駅描画、詳細表示
- `README.md`: このドキュメント

## 利用上の注意

データの基準日、項目の定義、利用条件は、配信元のデータ掲載ページとデータ説明書を確認してください。配信元サイトでは、データのダウンロードをもって利用規約に同意したものとみなす旨が案内されています。

表示内容は公開CSVを加工した参考情報です。実際に駅を利用する際は、各鉄道事業者が提供する最新の公式情報を確認してください。
