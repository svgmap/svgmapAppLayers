# ODPT リアルタイム運行情報 (LaWA)

[公共交通オープンデータセンター (ODPT)](https://ckan.odpt.org/) 等が提供する、全国のバスや路面電車などの GTFS Realtime データを取得し、SVGMap上に表示する汎用レイヤーアプリケーション(LaWA)です。

データカタログサイト(CKAN)から提供事業者とリソースを自動的に取得し、ドロップダウンから選択して地図上に可視化することができます。

## 主な機能

- **全事業者対応**: ODPTで提供されているProtocol Buffers形式のリアルタイムデータを動的に検索・切り替え
- **ライセンス自動追従**: データセットごとのライセンス（ODPT基本ライセンス、CC-BY、GTFS-RUなど）を解析し、UI上に動的に表示
- **車両位置 (`VehiclePosition`) の地図・軌跡表示**: 過去数分間の走行軌跡（ブルーのライン）と現在位置アイコンの描画
- 車両の状態（走行中、停車中、5分以上更新なし）に応じた色分け表示
- 車両アイコンを選択した際の車両・便・位置情報の詳細表示
- **ルート更新情報 (`TripUpdate`)**: 遅延・到着出発予測の表示、対応する車両を地図上で赤色にハイライト
- **運行情報 (`Alert`)**: 対象・原因・影響・有効期間などの一覧表示
- 路線ID、便ID、車両IDなどによる一覧のインクリメンタル絞り込み
- 30秒ごとの自動更新と手動更新

## 表示方法

`Container.svg` に次の `animation` 要素を追加します。例示した `[https://your-proxy.example](https://your-proxy.example)` は、後述するプロキシのベースURLに置き換えてください。

URLの末尾（`#proxy=...` の前）に `#データセットID` を付与することで、起動時に初期選択される事業者を指定できます（例: `#odpt_kanto_bus_all_lines`）。指定がない場合は関東バス等のデフォルト事業者が選択されます。

```xml
<animation
  x="-30000"
  y="-30000"
  width="60000"
  height="60000"
  xlink:href="./appLayers/publicTransportation/odptRealtimeTracking/odptRealtimeTracking.svg#odpt_kanto_bus_all_lines&proxy=https://your-proxy.example"
  data-cross-origin-proxy-required="true"
  class="公共交通"
  title="ODPT リアルタイム運行情報"
  visibility="hidden"/>
```

SVGMapをHTTP(S)サーバーで配信し、レイヤー一覧から有効にします。

## 操作方法

1. **バス事業者の選択**: ドロップダウンから閲覧したい事業者を選択します。（APIの構造解析のため数秒かかります）
2. **表示データの選択**: 次のいずれかを選択します。
   - **車両位置**: 車両アイコンをクリックすると詳細情報を表示します。
   - **ルート更新情報**: 便を開くと停留所ごとの到着・出発予測を表示し、対応車両が地図上にあれば赤色に強調します。
   - **運行情報**: 情報を開くと対象路線や停留所、原因、影響、有効期間などを表示します。

車両位置は選択中のデータ種別にかかわらず裏側で取得・更新されます。「今すぐ更新」を押すと、自動更新を待たずに最新データを取得します。

### 車両アイコンの凡例

| 色 | 状態 |
| --- | --- |
| 青 | 走行中 |
| オレンジ | 停車中 |
| グレー | 車両データ時刻から5分以上経過 |
| 赤 | `TripUpdate`から選択された車両 |

## プロキシ要件

本レイヤーは、用途の異なる2種類のプロキシを利用して動作します。両者を混同しないようご注意ください。

### 1. ODPT GTFS-RT専用プロキシ (Cloudflare Workers用・同梱)
GTFS Realtimeデータは、CORS制限の回避やAPIキーの隠蔽のため、専用のパススループロキシを介して通信します。`Container.svg` の `#proxy=` パラメータで指定するのは**こちらのURL**です。

アクセス先のエンドポイント形式:  
`GET {PROXY_BASE_URL}/gtfs/{resource_name}`  
*(※ `resource_name` はデータセット固有のIDがスクレイパーによって動的に挿入されます)*

**同梱のプロキシスクリプトについて:**
ディレクトリ内に、Cloudflare Workersで動作するプロキシコード（`cloudflareWorkerProxy.js`）を同梱しています。これを利用することで以下のバックエンドを構築可能です。
- **APIキーの秘匿**: 環境変数等にキーを持たせ、ブラウザには公開しない
- **エッジキャッシュ**: `15秒間` キャッシュし、ODPTサーバーへの負荷を抑える（規約準拠）
- **アクセス制御**: `Origin` および `Referer` を検証し、許可されたドメインからのアクセスのみを許可
- **自動フォールバック**: APIキーがない場合はパブリックAPI（`api-public.odpt.org`）へ自動フォールバック

### 2. 汎用CORSプロキシ (CKANカタログサイト取得用)
データセット一覧やライセンス情報を `ckan.odpt.org` から取得するため、汎用的なCORS回避プロキシを利用しています。
- 現在のソースコード（`odptCkanScraper.js`）内では、SVGMap.getCORSURL()により自動的にコンテナで設定されたプロキシが使用されます。

## データと更新

- 初回表示時および事業者・データ種別の変更時にデータを取得します。
- 表示中は30秒ごとに自動再取得します。
- 車両の軌跡はクライアント側で最大数分間保持され、更新のたびに再描画されます。
- 緯度・経度がない、または範囲外の車両は地図に表示されません。
- 運行判断には、各交通事業者が提供する公式情報もあわせて確認してください。

## ファイル構成

- `odptRealtimeTracking.svg`: 地図上のシンボルとコントローラー定義
- `odptBusLoc.html`: 操作画面UIとスタイル
- `odptBusLoc.js`: データ取得、描画、一覧表示、更新処理
- `odptCkanScraper.js`: ODPT CKANカタログのスクレイピング、ライセンス・リソース自動解析
- `gtfsRealtime.js`: GTFS Realtimeデータのデコーダー

*※ `gtfsRealtime.js` は本レイヤーの表示に必要なフィールドをデコードするための軽量実装であり、完全な汎用ライブラリではありません。*

## データ利用条件と免責事項

本レイヤーで表示するデータは、選択した事業者ごとに異なるライセンス（公共交通オープンデータ基本ライセンス、CC-BY 4.0、GTFS-RU 等）が適用されます。

- 適用されるライセンスと出典情報は、アプリ画面下部に動的に表示されます。必ずリンク先を確認の上で利用してください。
- 各事業者の定めた特定利用条件（画像の縦横比変更禁止など）を遵守してください。
- **本アプリで表示される位置・運行情報の正確性・完全性について、公共交通オープンデータセンターおよび各交通事業者は一切の責任を負いません。**
- **データの不備や遅延等に関するお問い合わせを、交通事業者へ直接行うことは固く禁じられています。**

GTFS Realtimeの仕様詳細については、[GTFS Realtimeリファレンス](https://gtfs.org/ja/documentation/realtime/reference/)を参照してください。
