# 厚生労働省「通いの場」マップ LaWA

厚生労働省が公開する全国の「通いの場」をSVGMap上で検索・閲覧するLaWAです。都道府県、市区町村、キーワード、活動内容、料金、送迎で絞り込み、地点を選んで開催情報や連絡先などを確認できます。

## 主な機能

- 掲載ページから最新データのURL、対象年月、出力日を毎回検出
- 実際のバイト内容からCSV／ZIPを判定
- UTF-8 BOM、引用符、カンマ、空欄、列順変更、未知列に対応
- 都道府県と連動する市区町村候補
- 名称、ふりがな、所在地、活動内容、その他を対象としたキーワード検索（空白区切りAND）
- 活動、料金、送迎による絞り込み
- 地点詳細、全件数、条件該当件数、地図対象件数、現在の個別地点記号数、除外件数の表示
- 約1.5万件向けのClient-Side QTCT描画
- 通信失敗時の日本語エラーと手動再読込

## データソース（2026年7月31日確認）

- 提供元: 厚生労働省／介護サービス情報公表システム
- 掲載ページ: [通いの場のオープンデータ](https://www.mhlw.go.jp/stf/kayoinoba_opendata_00002.html)
- 確認時に検出したデータ: [2026年6月末データ](https://www.mhlw.go.jp/content/12300000/202606.csv)
- 提供元出力日: 2026年7月9日
- 更新時期: 毎年6月末・12月末時点

2026年7月31日の実レスポンスはHTTP 200、`Content-Type: text/csv`、`Content-Disposition`なし、6,195,590バイト、UTF-8 BOM（`EF BB BF`）付きCSVでした。掲載ページには「CSVファイルをZIP形式で圧縮」と記載されていますが、現行URLはZIPではなくCSV本体を返します。このため、拡張子や案内文だけに依存せず、ZIPマジックナンバーと実内容で判定します。

現行CSVは38列・15,486行です。経緯度欄は全行に値がありますが、3件が`0,0`でした。この3件は日本域外として除外します。北海道、東京都、沖縄県の実在地点で経度・緯度の順と表示位置を確認しています。現行データに同一`No`はありませんでした。

### 最新データURLの検出

1. 掲載ページを`svgMap.getCORSURL()`経由で取得します。
2. CSVまたはZIPへリンクするリスト項目から、「YYYY年M月末」と出力日を抽出します。
3. 対象年月が最も新しい候補を選び、相対URLを掲載ページ基準で絶対URLにします。
4. URL、対象年月のどちらかを安全に抽出できない場合は処理を停止します。既知URLを「最新」とみなすフォールバックは行いません。

## データ処理

処理の流れは次のとおりです。

1. 掲載ページとデータをタイムアウト付きで取得
2. HTTP状態、Content-Type、サイズ、CSV／ZIP形式を検証
3. ZIPの場合は`commonLib/unzipit.module.js`で展開し、CSVが1ファイルだけであることを確認
4. UTF-8としてデコードし、`commonLib/parseCsv.js`でRFC 4180相当のCSV解析
5. BOMとヘッダー表記を正規化し、列番号ではなく列名で解決
6. 必須列、データ行数、座標を検証
7. 検索用正規化文字列、地域候補、活動・料金・フラグ分類を1回だけ作成
8. 絞り込み後の地点をQTCT化し、表示範囲と縮尺に応じて集約画像または個別記号を描画

同一`No`は最初の行を優先します。`No`が空の場合は、都道府県コード、市区町村コード、正規化名称、正規化所在地、緯度、経度の複合キーで重複を判定します。

座標は数値・世界値域に加え、対象が日本全国であることから緯度20〜46度、経度122〜154度の範囲を検証します。欠損、非数値、世界値域外、日本域外を別々に集計します。

## 分類基準

### 活動内容

自由記述を次の順に複数分類し、最初に一致した分類を地点記号へ使います。フィルターでは複数分類のどれに一致しても対象になります。

- 体操・運動: 体操、運動、スポーツ、ウォーキング、ヨガ、ストレッチなど
- 介護・認知症予防: 認知、脳トレ、介護予防、口腔、健康、フレイル
- 交流・茶話: 茶話、交流、サロン、カフェ、つどい、多世代など
- 食事・栄養: 会食、食事、調理、料理、栄養、ランチなど
- 趣味・文化: 趣味、レクリエーション、カラオケ、手芸、囲碁、音楽など
- その他: 記載はあるが上記語句に一致しないもの
- 記載なし: 空欄

分類は検索補助のための加工であり、提供元の公式分類ではありません。

### 料金

自由記述から金額自体は推測しません。

- 無料: 「無料」「無償」「参加費なし」「不要」「0円」など、無償であることが明記
- 有料: 0円以外の金額、「有料」「実費」「材料費」「会費制」「月額」など、負担が明記
- 不明: 空欄、未定、要問合せ、または判定根拠となる表現がないもの

「無料（材料費あり）」のように別途負担が明記される場合は有料へ分類します。

### 0／1フラグ

現行実データでは「飲食の提供の有無」「飲食持ち込みの可否」「送迎の有無」「総合事業実施の有無」が`0`、`1`、空欄で構成されています。項目名の有無・可否と公表システム上の表示（例: `法人番号の有無=0`の地点が「法人番号なし」）を照合し、`1=あり／可`、`0=なし／不可`とします。空欄と未知値は不明です。別の公式コード表が公開された場合は再確認が必要です。

## 大量ポイント描画

全件を`use`要素として常時DOMへ追加せず、`commonLib/ClientSideQTCT.js`をラップする`commonLib/QTCTLayerRenderer.js`を使用します。

- 縮小時: 低解像度の集約画像タイル
- 拡大時: 表示範囲内の個別地点記号
- パン・ズーム時: 必要なタイルだけ差し替え
- フィルター: 280msのデバウンス
- 連続変更時: 古いQTCT構築結果を描画せず、最後の条件を再構築
- 元CSVと検索用文字列: 初回取得時に1回だけ解析・構築

画面の「地図対象」は条件に一致して有効座標を持つ全件数、「現在の個別記号」は現在DOMにある個別地点数です。縮小時は個別記号が0件でも集約画像が表示されます。

## CORSプロキシ

`www.mhlw.go.jp`の確認時レスポンスには`Access-Control-Allow-Origin`がありません。掲載ページとデータ本体の両方を`svgMap.getCORSURL()`経由で取得します。

- プロキシ許可が必要なホスト: `www.mhlw.go.jp`
- 認証・APIキー: 不要
- `Container.svg`: `data-cross-origin-proxy-required="true"`を設定

プロキシが未設定、対象ホストが未許可、提供元が停止中の場合は読み込みに失敗します。「データを再読込」を押して再試行し、継続する場合はSVGMap側のCORSプロキシ設定と許可ホストを確認してください。

## 操作

1. `Container.svg`から「厚労省 通いの場」を表示します。
2. 初回取得とQTCT構築の完了を待ちます。
3. 都道府県を選ぶと市区町村候補が切り替わります。
4. キーワード、活動、料金、送迎を必要に応じて組み合わせます。
5. 地点記号を選ぶと、名称、所在地、対象者、開催時間、料金、飲食、送迎、連絡先などを表示します。
6. 「条件をリセット」で全件表示へ戻します。
7. 通信失敗時やデータ更新確認時は「データを再読込」を使います。

取得は初期表示時と手動再読込時だけです。検索や地図移動による再取得、自動ポーリングは行いません。

## ファイル構成

- `kayoinoba.svg`: CRS84、活動別地点記号、コントローラー参照
- `kayoinoba.html`: 日本語UI、凡例、件数、出典、注意事項
- `kayoinoba.js`: 通信、ZIP展開、UI、QTCT描画、後片付け
- `kayoinobaCore.js`: URL検出、形式判定、CSV正規化、分類、検索、詳細DOM生成
- `test/fixtures/`: 通信不要の掲載ページ・CSVフィクスチャ
- `test/kayoinobaCore.test.js`: 純粋処理と安全な詳細表示のテスト
- `test/structure.test.js`: SVG、HTML、Container参照、アクセシビリティ構造のテスト
- `test/browserHarness.html`: 実データをローカル供給するブラウザー検証用ハーネス

HTMLは`svgMapLayerLib.js`を読み込み、`layerWebAppReady`後に初期化します。`window.parent`へ依存せず、T-LaWA／S-LaWA双方を意識した構成です。終了時は通信、タイマー、イベント、生成済みQTCTデータを破棄します。

## 制限と公開前確認

- 元データは自治体の登録状況に依存し、網羅性、正確性、最新性は保証されません。
- 料金・活動分類は自由記述への保守的なルールベース加工です。
- 座標が有効でも、提供元の位置精度をこのLaWAで保証するものではありません。
- 掲載ページ構造、列名、0／1コードの定義が変わった場合は更新が必要です。
- 本番CORSプロキシで`www.mhlw.go.jp`が許可されていることを公開前に確認してください。
- 提供元はデータ利用時の連絡フォームへの一報を依頼しています。公開運用者が必要に応じて対応してください。
