# 沖縄県オープンデータ LaWA

沖縄県オープンデータカタログのうち、緯度・経度または住所を持つ表形式データをSVGMap上に表示します。

- データセット一覧: https://data.bodik.jp/organization/470007
- 参考LaWA: https://www.svgmap.org/demos/exclusiveDemos/yamaguchiPref/
- CSVはUTF-8 / Shift_JISを自動判定します。
- XLS / XLSXしかない場合はSheetJSで先頭シートをCSVへ変換します。
- データセットに複数のリソースがある場合は、画面で選択できます。初期値は最新のCSVです。
- 表示時に空欄・数値範囲外・`0,0`の位置情報を除外し、沖縄付近の値から経緯度逆転も判定します。
- 緯度・経度がない場合は住所・所在地列（または都道府県、市区町村、町字、番地などの分割列）を検出し、CSIS簡易ジオコーディングで座標を付与します。同じ住所は1回だけ検索し、同時リクエストは3件に制限します。
- データセットの名称・説明・タグから種類を判定し、`img`フォルダへローカル保存したGoogle FontsのMaterial Symbols Rounded SVG（飲食、自然、教育、子育て、医療、介護、駐車場、Wi-Fi、イベント、文化、観光、選挙、公共施設、店舗）を地図アイコンに使用します。
