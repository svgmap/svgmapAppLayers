# 令和8年熊本地震 正射画像 LaWA

国土地理院の被災後正射画像（XYZ PNG）を表示するT-LaWAです。

- 掲載ページ: `https://www.gsi.go.jp/BOUSAI/20260728_kumamoto_earthquake.html`
- 取得方法: 起動時と「最新データを再取得」押下時に掲載ページを取得し、地理院地図リンクから正射画像レイヤーを自動抽出
- データ: 抽出した公式レイヤーIDから `https://maps.gsi.go.jp/xyz/{レイヤーID}/...` を生成
- 更新方法: 撮影日の新しい順に選択肢を生成し、代表タイルを取得できた正射画像だけを表示
- ライセンス: 国土地理院コンテンツ利用規約。画面上に出典を表示します。
- CORS: 掲載ページと `maps.gsi.go.jp` の `/xyz/` を `svgMap.getCORSURL()` 経由で取得します。

取得したURLは国土地理院の熊本地震用正射画像レイヤーに限定して検証します。取得できない正射画像は一覧から除外し、掲載ページの取得・解析に失敗した場合は現在の一覧（初回は内蔵一覧）を維持します。正射画像は表示範囲・ズームに応じてタイルを差し替えます。
